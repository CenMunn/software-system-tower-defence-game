# 软件体系塔防游戏（Software System Tower Defence Game）

一个在软件体系课程中完成的塔防（Tower Defence）游戏，基于 C++ 与 Qt 图形界面框架开发。玩家通过在地图上的固定塔位建造炮塔，抵御一波波沿固定路线入侵的敌人，保护基地不被攻破。

## ✨ 功能特性

- **经典塔防玩法**：敌人沿预设路径行进，到达终点会扣除基地生命值
- **多波敌人系统**：怪物按波次生成，难度逐渐提升
- **多种敌人类型**：
  - `enemy`：基础敌人（攻击力 20，奖励 70 金币）
  - `enemyUp`：强化敌人（攻击力 30，奖励 120 金币）
  - `enemyUpUp`：特殊敌人（攻击力 10，奖励 50 金币）
- **多种炮塔类型**：地图上共有 11 个塔位，可建造普通塔（100 金币）与升级塔（120 金币）
- **经济系统**：击杀敌人获得金币，用金币建造炮塔
- **胜负判定**：生命值归零则失败，守住全部波次则胜利
- **暂停/继续**：游戏内可随时暂停
- **游戏说明**：主菜单可查看玩法介绍

## 🎮 游戏规则

- 初始资源：**800 金币、500 生命值**
- 点击地图上的空白塔位（金币充足时）即可建造炮塔
- 炮塔自动攻击射程内的敌人
- 敌人抵达路径终点会扣除基地生命值
- 生命值归零游戏失败，成功防守全部波次则获胜

## 🛠 技术栈

- **语言**：C++11
- **框架**：Qt（Qt 5 / Qt 6，已在 Qt 6.9.1 MinGW 64-bit 下构建验证）
- **构建工具**：qmake

## 🚀 构建与运行

### 方式一：Qt Creator（推荐）

1. 安装 Qt（Qt 5 或 Qt 6，MinGW 工具链）
2. 用 Qt Creator 打开 `DQ-1.pro`
3. 配置构建套件后，点击运行 ▶

### 方式二：命令行

```bash
cd tafangyouxi/最终提交版本/Code/DQ
qmake DQ-1.pro
mingw32-make          # Windows / MinGW
# 或 make             # Linux / macOS
```

编译完成后运行生成的 `DQ-1` 可执行文件。

## 🖼 操作说明

| 操作 | 说明 |
| --- | --- |
| 主菜单「开始游戏」 | 进入游戏 |
| 主菜单「游戏说明」 | 查看玩法介绍 |
| 主菜单「退出」 | 退出游戏 |
| 点击空白塔位 | 建造炮塔（消耗金币） |
| 右上角按钮 | 暂停 / 继续游戏 |
